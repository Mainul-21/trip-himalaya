# Loading Reference Notes

## Source observed

- URL: https://tresswidetrip.in/
- Observation date: 2026-08-23

## Visible inspiration captured

The reference displayed a clean white loading screen with a central **globe** motif and a small **aircraft / journey** visual. Its general impression was travel-oriented, uncluttered, and centered rather than a branded splash screen.

## Trip Himalaya adaptation

Trip Himalaya does **not** reuse the reference logo, imagery, copy, asset URLs, reviews, claims, or code. The implementation uses original Lucide `Globe2` and `Plane` icons, a Trip Himalaya navy, orange, and teal palette, independently written motion and copy, and the existing reduced-motion rule. The Plan Your Trip and WhatsApp actions remain Trip Himalaya’s own working conversion paths.
