# Requested Experience Research Notes

## Source reviewed
[Himachal Pradesh Tourism Development Corporation](https://hptdc.hp.gov.in/)

The official HPTDC page presents Himachal Pradesh as a Himalayan travel destination and includes public destination/activity context for Bharmaur–Chamba, Billing paragliding, McLeod Ganj/Dharamshala, Khajjiar/Chamba, cultural experiences, religious destinations, cottages, and tourist attractions. It supports using concise, non-quantified descriptions for the owner-provided destination and activity names.

## Implementation guardrails

Use the owner-provided names as the source of truth for the editable experience labels. Do not invent prices, durations, availability, ratings, traveller counts, certifications, or “verified” claims. Because local availability and operator details vary, descriptions should remain high-level and enquiry-led, such as “Plan with our local team” rather than asserting that every activity is always offered. Preserve existing administrator editing and public data bindings.

The second official Himachal Tourism URL attempted was unavailable during this check (`ERR_CONNECTION_CLOSED`), so no claims from that page are used.
